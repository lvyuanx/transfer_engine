# 文件操作系统消息设计文档

## 目标
- 上传、下载、删除、创建目录均产生「系统」用户聊天消息，成功与失败都发。
- 补齐上传、删除、创建目录能力，并适配现有文件树 UI。
- 复用现有 SQLite 聊天持久化（ChatStore）与 ChatRoom 广播。

## 接口
1. `POST /api/upload?dir=` multipart 上传一个或多个文件到指定目录，返回 `{uploaded: [...], failed: [...]}`；目录不存在返回 400/404。
2. `POST /api/dirs` JSON `{name}` 创建目录（名称校验、同级重名校验），返回 `{path}`。
3. `DELETE /api/files?path=` 删除文件或目录（目录递归删除），返回 `{deleted: path}`。
4. 下载保持 `GET /api/download?path=`；失败时也会发系统消息。

## 系统消息
- 成功：`上传了文件「hello.txt」到「docs」` / `下载了文件「hello.txt」` / `删除了文件「hello.txt」` / `创建了目录「docs」`。
- 失败：`上传失败：<原因>` / `下载失败：<原因>` / `删除失败：<原因>` / `创建目录失败：<原因>`。
- 由「系统」用户名发送，走 ChatStore.append + ChatRoom.broadcast，可被持久化与历史查询。

## 前端
- 根工具栏：新增「上传」「新建文件夹」按钮；上传支持多选文件到根目录。
- 每个目录行：新增「+」上传到此目录、「×」删除按钮；文件行新增「×」删除按钮；删除前 confirm。
- 文件树操作后局部刷新对应目录，避免整树重建。

## 限制
- 上传大小默认每文件 500 MB，可用 `--max-upload-size` 配置。
- 名称/路径安全校验沿用 safe_resolve，禁止穿越、隐藏文件。
- 删除任意文件/目录（公共工具），前端二次确认。

## 测试
- 上传成功/失败系统消息与文件落盘；创建目录成功/失败；删除成功/失败；下载成功/失败系统消息。
- 名称/路径校验、上传大小限制、目录不存在、文件树刷新。
- e2e 冒烟验证上传接口与系统消息接口。
